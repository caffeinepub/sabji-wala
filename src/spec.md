# Specification

## Summary
**Goal:** Create an initial “Sabji wala” branded app with a simple, polished landing page, consistent non-blue/purple theme, and a minimal backend-powered app info display.

**Planned changes:**
- Update frontend branding to “Sabji wala” (on-page header/title and browser/tab document title) with all user-facing text in English.
- Build a landing page layout (header + hero + at least one informational section) suitable for a fresh-produce/vegetable shop concept, without any commerce flows.
- Apply a coherent visual theme (colors, typography, spacing, component styling) that feels intentionally designed and avoids blue/purple primary colors.
- Add a minimal backend endpoint that returns basic app info including the name “Sabji wala”, and fetch/render it on the landing page with a sensible loading state.
- Add generated static image assets under `frontend/public/assets/generated` and use them on the landing page (e.g., logo in header, hero illustration in hero).

**User-visible outcome:** Users see a branded “Sabji wala” landing page with a consistent fresh-produce theme, a logo and hero illustration, and the app name rendered from the backend with a loading state while it fetches.
